XSLT Bridge · guide

View CDISC define.xml in Chrome and Edge

A CDISC define.xml file depends on XSLT to display as a readable page. Chrome and Microsoft Edge remove built-in XSLT by default starting with version 158, on November 17, 2026. After that, a define.xml opened in the browser shows raw XML instead of the dataset and variable tables.

Local files already have a problem. In our test with the CDISC sample define.xml, the file displayed from a web server, but opened from a local folder it showed a blank page in Chrome, before the XSLT change.

Check in one minute

You can see the effect today, before your browser updates:

  1. Close every Chrome (or Edge) window. If one stays open, the setting is ignored.
  2. Press Windows + R and type chrome --disable-blink-features=XSLT (for Edge: msedge --disable-blink-features=XSLT).
  3. Open a define.xml from a recent submission package.

To go back, close the browser and open it normally.

How to keep it readable

  • Create an HTML copy. Apply the stylesheet with your programming language or mapping tool and keep a define.html alongside the define.xml. If you're preparing a submission, this is the safe choice, because you can't control which browser a reviewer uses.
  • Use a browser extension for files you open day to day. XSLT Bridge displays define.xml from web servers and from approved local folders, using the file's own stylesheet. It runs only where you or your IT team approve, and it sends nothing to us automatically.
