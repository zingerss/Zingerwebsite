Zinni · in testing

One assistant across Zinger products

Zinni is the assistant we are building into Zinger products. You ask a question in plain language; Zinni is designed to answer from the case in front of you and point to the lines and documents its answer rests on.

Zinni is in closed testing inside ZinPulse, our workout app, and in development for Zinvera's first pilot release. It is not yet in a public release.

In Zinvera

Questions about the return

Planned for the first pilot release: the reviewer asks a question about the case in plain language and gets an answer that points to the return lines and document fields it rests on.

The review engine's tax rules run today, and every number stays in code. Zinni is designed to explain, not to compute the figures.

In ZinPulse

A coach that shows its work

In closed testing: Zinni designs multi-week programs, builds a session for the time and energy you have, adjusts routines on request and answers training questions from your own workout log.

The scores in ZinPulse (readiness, program match, weight targets) come from code on the phone, and tapping one shows the maths. Zinni works from those numbers and plans around any joints you flag. It runs on Claude by Anthropic, only after you allow it.

Design rules

How Zinni is meant to answer

The same rules as every Zinger AI product.

Numbers come from code

Zinni is designed to quote figures the product's code has already computed, not to do the arithmetic itself.

Sources are shown

An answer points to the line, field or document behind it, so you can check it.

People decide

Zinni is designed to explain and point. The decision stays with you.

Your data

Pilots run on synthetic data

The Zinvera pilot uses synthetic case files only and accepts no client data. We do not use client data to train AI models.
